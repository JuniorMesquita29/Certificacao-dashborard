# Certificação — Ganho e Pipeline

Dashboard estático da fila de certificação da China Link (projeto Projeção de Custos no CLP / Teamwork).

A página é `index.html`, pronta para o GitHub Pages na branch `main`, pasta raiz.

Endereço esperado: https://juniormesquita29.github.io/Certificacao-dashborard/

Todos os números saem de [`data/metrics.json`](data/metrics.json). Para gerar uma extração nova e publicar, siga [`scripts/README.md`](scripts/README.md).

Receita, custo, margem e conversão de cotação em projeto não estão na extração. O site lista esses campos em "Dados necessários" e não desenha gráfico para eles.

Abrir `index.html` direto do disco (`file://`) bloqueia a leitura do JSON. Use o GitHub Pages ou um servidor local.
